\# MLflow Assignment



\## Objective



This project demonstrates machine learning experiment tracking using MLflow.



\## Tools Used



\- Python

\- Scikit-learn

\- MLflow

\- Git

\- GitHub



\## Dataset



The Iris dataset from Scikit-learn is used for training and evaluation.



\## Model



A Random Forest Classifier is trained using:



\- n\_estimators = 100

\- max\_depth = 3

\- test\_size = 0.3

\- random\_state = 42



\## MLflow Tracking



MLflow tracks:



\- Model parameters

\- Accuracy metric

\- Trained Random Forest model
